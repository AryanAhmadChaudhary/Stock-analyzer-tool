# Real-Time Stock Analyzer Tool

## Overview
This project is an AI-powered real-time stock analysis system that combines market data, financial indicators, and large language models to generate actionable insights for any selected stock.
The application provides:
*  Live stock metrics
*  Market sentiment analysis
*  Automated SWOT (Strengths, Weaknesses, Opportunities, Threats) reports

The system is built with Streamlit for interactive analysis and is additionally integrated with Claude Desktop using the Model Context Protocol (MCP), allowing it to be used as a callable AI tool outside the browser.

## Key Features

*   **Interactive Stock Analysis Dashboard** 
*   **Real-Time Market Metrics** 
*   **AI-Based Sentiment Analysis**
*   **Automated SWOT Report Generation** 
*   **MCP-Based AI Tool Integration into Claude**
